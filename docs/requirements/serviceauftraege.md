Mit dieser App können Sie Serviceaufträge verwenden, um die Details zu einer einmaligen Serviceleistung anzugeben, die zwischen einem Servicegeber und einem Servicenehmer vereinbart wurde. Wenn eine Serviceleistung ausgeführt wurde, können Sie dies mithilfe einer Servicerückmeldung erfassen. Diese App ist mit dem Finanzwesen, der Fakturierung, dem Controlling, der Bestandsführung und der Beschaffung integriert, was Ihnen einen nahtlosen und durchgängigen Serviceprozess ermöglicht.
Die App Serviceaufträge verwalten unterstützt folgende Funktionen:
Sie können alle Serviceaufträge im System auflisten, die Ergebnisse filtern oder nach bestimmten Serviceaufträgen suchen. Außerdem können Sie Serviceaufträge anzeigen, anlegen und bearbeiten. Weitere Informationen über Serviceaufträge finden Sie unter [Serviceaufträge](https://help.sap.com/docs/SAP_S4HANA_CLOUD/adbae5bcd5994f159bf2847a11397b61/37cb01e45ca9480a9e879e5132424879.html?locale=de-DE&state=PRODUCTION&version=2608.500 "In diesem Abschnitt werden Serviceaufträge und die auf Kopfebene von Serviceaufträgen verfügbaren Funktionen vorgestellt.").
Sie können Servicerückmeldungen auf der Basis von freigegebenen Serviceaufträgen anlegen, um die Serviceausführung zu bestätigen. Das System kopiert alle relevanten Serviceauftragsdaten in die Servicerückmeldung. Sie können die in die Servicerückmeldung kopierten Daten bei Bedarf bearbeiten. Weitere Informationen zu Servicerückmeldungen finden Sie unter [Servicerückmeldungen](https://help.sap.com/docs/SAP_S4HANA_CLOUD/adbae5bcd5994f159bf2847a11397b61/f51f9127ec904db69be5bfc40cfcaeb4.html?locale=de-DE&state=PRODUCTION&version=2608.500 "In diesem Abschnitt werden Servicerückmeldungen und ihre Funktionen vorgestellt.").
Sie können verschiedene Arten von Positionen, z.B. Ausgabenpositionen, verwenden, um Details zu einem Serviceauftrag anzugeben und den Servicevorgang in Servicerückmeldungen zu erfassen. Weitere Informationen zu Positionen in Serviceaufträgen und Servicerückmeldungen finden Sie unter [Positionen](https://help.sap.com/docs/SAP_S4HANA_CLOUD/adbae5bcd5994f159bf2847a11397b61/3a2f024ad33345f393ef8b9f3bf0a858.html?locale=de-DE&state=PRODUCTION&version=2608.500 "In diesem Abschnitt wird erklärt, wie Positionen in Serviceaufträgen und Servicerückmeldungen verwendet werden und welche Funktionen sie haben können.").
Sie können Ihren Kunden Servicepositionen, Ersatzteile und Ausgabenpositionen als Paket anbieten. Ein Servicepaket besteht aus einer Hauptposition und einer oder mehreren untergeordneten Positionen. Weitere Informationen finden Sie unter [Servicepakete](https://help.sap.com/docs/SAP_S4HANA_CLOUD/adbae5bcd5994f159bf2847a11397b61/b77e6c372a464a7dad9792167495f258.html?locale=de-DE&state=PRODUCTION&version=2608.500 "Sie können Servicepakete verwenden, um Kunden Serviceprodukte, Ersatzteile und Ausgabenpositionen als \"Paket\" anzubieten.").
Sie können eine Servicegruppe zuordnen, die für die Ausführung des Serviceauftrags zuständig ist. Weitere Informationen finden Sie unter [Servicegruppen](https://help.sap.com/docs/SAP_S4HANA_CLOUD/adbae5bcd5994f159bf2847a11397b61/0ebd52ee5654449894267283b386b48c.html?locale=de-DE&state=PRODUCTION&version=2608.500 "Eine Servicegruppe ist eine Organisationseinheit, der Servicemitarbeiter für die Ausführung von Serviceaufgaben zugeordnet sind. Sie erleichtert die Zuordnung von Servicemitarbeitern in Servicevorgängen, zugehörige Analysen sowie die Suche nach Servicevorgängen.").
Mit dieser App können Sie verschiedene zentrale Aspekte der Serviceausführung überwachen. Ein Serviceauftrag kann beispielsweise den Status Wird ausgeführt oder Ausführungsplanung haben.
Sie können Serviceaufträge für die Fakturierung freigeben. Der Serviceauftragskopf und alle zugehörigen Serviceauftragspositionen müssen den Status Erledigt haben. Wenn Sie die Teilfakturierung verwenden, müssen die Servicerückmeldung und die entsprechende Serviceauftragsposition auf Erledigt gesetzt werden. Nachdem Sie den Serviceauftrag für die Fakturierung freigegeben haben, legt das System die erforderlichen Fakturaanforderungen an. Weitere Informationen über die Fakturierung finden Sie unter [Fakturierung](https://help.sap.com/docs/SAP_S4HANA_CLOUD/adbae5bcd5994f159bf2847a11397b61/6a020691baf84df09b067d1dd156de4a.html?locale=de-DE&state=PRODUCTION&version=2608.500 "Erhalten Sie einen Überblick darüber, wie Service und Sales Billing zusammenarbeiten, um die Fakturierung von Servicevorgängen zu erleichtern.").
Mithilfe eines Fakturierungsplans für Ad-hoc-Fakturierung können Sie die Termine, an denen fakturiert werden soll, und den Betrag, der in den Positionen mit Festpreis fakturiert werden soll, angeben. Für jedes Fakturadatum generiert das System eine Fakturaanforderungszeile. Weitere Informationen zu Fakturierungsplänen für Ad-hoc-Fakturierung finden Sie unter [Ad-hoc-Fakturierung für Serviceaufträge](https://help.sap.com/docs/SAP_S4HANA_CLOUD/adbae5bcd5994f159bf2847a11397b61/05cfcc6eeaf34164b29219c47965d934.html?locale=de-DE&state=PRODUCTION&version=2608.500 "Sie können die Ad-hoc-Fakturierung verwenden, um Fakturawerte und -termine für Festpreis-Serviceauftragspositionen frei festzulegen. Besonders nützlich ist diese Funktion, wenn Sie Fakturaanforderungen für Festpreis-Serviceauftragspositionen mit langer Dauer anlegen möchten, die Sie zu bestimmten Terminen abrechnen möchten und nicht erst, wenn die Serviceauftragsposition erledigt ist.").
Hinweis
Um sicherzustellen, dass das System die Fakturaanforderungen in einer einzelnen Rechnung zusammenführt, die den vereinbarten Festpreis enthält, muss die Fakturierungseinstellung, die dafür sorgt, dass für jede Position des Fakturavorrats eine eigene Faktura angelegt wird, in der App Fakturen anlegen ausgeschaltet werden.
Einem Serviceauftrag können mehrere Servicerückmeldungen zugeordnet sein. Bevor ein Serviceauftrag auf Erledigt gesetzt wird, müssen alle auf diesem Serviceauftrag basierenden Servicerückmeldungen auf Erledigt gesetzt und eine Servicerückmeldung als Endrückmeldung gekennzeichnet sein.
Mit der Geschäftspartnerverarbeitung können Sie steuern, wie das System mit Geschäftspartnern in Servicevorgängen umgeht. Diese Funktion erleichtert Ihnen die Arbeit, indem bestimmte Partner und zugehörige Informationen, z.B. Adressen, automatisch eingegeben werden.
Einer der wichtigsten Aspekte der Partnerverarbeitung ist die Partnerfindung. Mit ihr können Sie die Partner, die an einem Vorgang beteiligt sind, automatisch finden und eingeben. In den meisten Vorgängen geben Sie einen oder mehrere Partner manuell ein. Die restlichen Partner werden vom System durch Partnerfindung ergänzt.
             Mit der Funktion Alternativen vorschlagen können Sie die Partnerfindung in einem Serviceauftrag anstoßen, um zuvor automatisch ermittelte Partner in der App zu ändern. So ist eine manuelle Suche nach Partnern, die Sie ersetzen möchten, nicht nötig. Die Funktion kann auch verwendet werden, um Partner in gesicherten Vorgängen neu zu ermitteln, und um die Partnerfindung für leere Partnerfunktionen anzustoßen, die zuvor in einem Vorgang gesichert wurden.
Hinweis
Voraussetzung ist, dass die Geschäftspartner in den Stammdaten gepflegt sind, damit das System diese finden und verwenden kann, um Alternativen vorzuschlagen. Darüber hinaus hängt die Partnerfindung davon ab, wie die Zugriffsfolgen definiert werden. Zugriffsfolgen sind Suchstrategien zur Angabe der Datenquellen, die das System für die Partnerfindung verwendet, sowie zur Angabe der Reihenfolge, in der es diese Quellen verwendet, und der zugehörigen Details. Die Quellen können Geschäftspartner-Stammdaten, Organisationsdaten und der Vorgängervorgang sein.
             Sie können Profitcenter für Serviceauftragspositionen und Servicerückmeldungspositionen ermitteln. Weitere Informationen finden Sie unter [Profitcenter-Findung für Servicevorgänge](https://help.sap.com/docs/SAP_S4HANA_CLOUD/adbae5bcd5994f159bf2847a11397b61/4d5e9cef91ef46ed8eb75c8d90f32e94.html?locale=de-DE&state=PRODUCTION&version=2608.500 "Verschaffen Sie sich einen detaillierten Überblick über die Profitcenter-Findung für Servicevorgangspositionen.").
Hinweis
Sie können das Profitcenter für Serviceauftragspositionen nicht mehr ändern, wenn die zugehörigen Servicerückmeldungen storniert oder erledigt wurden.
Sie können Projektstrukturplan-Elemente (PSP-Elemente) als Attribute von Ergebnisobjekten zu Serviceaufträgen und Servicerückmeldungen zuordnen. Weitere Informationen finden Sie unter [PSP-Element im Service](https://help.sap.com/docs/SAP_S4HANA_CLOUD/adbae5bcd5994f159bf2847a11397b61/26052849db2e4258975e91e9376a9dd8.html?locale=de-DE&state=PRODUCTION&version=2608.500 "Sie können Projektstrukturplan-Elemente (PSP-Elemente\) als Attribute zu Servicevorgängen zuordnen.").
Sie können Dateien und URL-Links an Serviceaufträge (Serviceauftragskopf und Serviceauftragsposition) und Servicerückmeldungspositionen anhängen. Außerdem können Sie Anlagen herunterladen und löschen. Weitere Informationen zu Anlagen in Service SAP S/4HANA Cloud Public Edition finden Sie unter [Anlagenservice](https://help.sap.com/docs/SAP_S4HANA_CLOUD/adbae5bcd5994f159bf2847a11397b61/e7ff65b0c2c34652995745c9416edc5e.html?locale=de-DE&state=PRODUCTION&version=2608.500).
Sie können Fakturierung, Kostenbuchung und Abrechnung im Rahmen der Serviceauftragsabwicklung über mehrere Buchungskreise hinweg verarbeiten. Das buchungskreisübergreifende Szenario ist für Servicepositionen und Ausgabenpositionen in Serviceaufträgen und Servicerückmeldungen verfügbar. Weitere Informationen finden Sie auch im Umfangsbestandteil Interne Verrechnung für Servicebelege (53Y).
Für Kostenbuchungen können Sie alle buchungskreisübergreifenden Buchungen erlauben oder sperren oder eine Erlaubtliste für bestimmte Kombinationen aus Sender- und Empfängerbuchungskreisen definieren. Verwenden Sie dazu die Konfigurationsaktivität Buchungskreisübergreifende Buchungen sperren in Ihrer Konfigurationsumgebung. Weitere Informationen finden Sie unter [Buchungskreisübergreifende Buchungen](https://help.sap.com/docs/SAP_S4HANA_CLOUD/adbae5bcd5994f159bf2847a11397b61/f122df1000404a34ae13275a79dbf0c8.html?locale=de-DE&state=PRODUCTION&version=2608.500 "Erfahren Sie, welche Apps Sie verwenden können und welche Konfigurationsoptionen Sie für die Handhabung buchungskreisübergreifender Buchungen haben.").
Hinweis
Das buchungskreisübergreifende Szenario wird für Ersatzteilpositionen nicht unterstützt.
Sie können Berechnungsmotive verwenden, um das Kalkulationsschema zu beeinflussen und Positionen in Serviceaufträgen und Servicerückmeldungen anhand von Skontosätzen, z.B. Kulanz oder Garantie, zu unterscheiden. Sie können entweder das Berechnungsmotiv mit dem Schlüssel S2 verwenden oder mit der Konfigurationsaktivität Berechnungsmotive für Service definieren in Ihrer Konfigurationsumgebung eigene Berechnungsmotive konfigurieren.
