# Preview 0.10 · Facharbeitsplätze und PDF-Anlagen

Tatsächliche Chromium-Aufnahmen vom22.10.2026 mit offiziellen **OpenUI5-Standardcontrols1.152.1**, Horizon und ausschließlich isolierten PostgreSQL-Testbelegen. 128 automatisierte Prüfungen; alle zwölf Browserketten einschließlich Smartphone-Menü und Anlagen-Dialog bestanden mit diesem Patchstand. [Versionsumfang und offene Masterprompt-Punkte](../../releases/v0.10.0-preview.1.md).

App-Zentrale bleibt Einstieg, obere Schnellzugriffe gehören ausschließlich zur aktiven Anwendung. Die Masken zeigen tatsächliche Beleg-, Mengen-, Wert-, Status-, Organisations- und Zuständigkeitsdaten. PDF-Anlagen öffnen sich als kleiner nativer Dialog. Android-Aufnahmen sind Chromium-Mobilprofile, keine Behauptung eines physischen Gerätetests.
